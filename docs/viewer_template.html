Conditional recoverability: saved model trajectories

Synthetic, uncalibrated ODE calculations in dimensionless time. This viewer reads saved nominal trajectories; it does not simulate new settings, fit parameters, or establish clinical efficacy. All data and figures are embedded, so the file works offline without a server.

Move the pointer over the plot to read the nearest saved row.

Controls and states

x is impairment; s is the slow commanded-drive state, active only in M3; d is structural loss, active only in M4. Inactive placeholders are not plotted. Functional output is F=(1−d)(1−x). This plot shows states, not observed cognition or patient outcomes.

All nominal rows start at the largest attracting pretreatment equilibrium. Nominal post-drive a=0.06, feedback b=4 and baseline repair r=1.05; pretreatment a=0.14. Drive reduction is 0.08. Repair increment is 0.4 during [30,45). M3 uses τ=1,10 or50; τ has the same dimensionless time units. The M4 dataset here is the separate Stage D example: d=0.15 fixed, ε=η=0, xc=0.25, maintained combination only. Evolving M4 and alternative M4 policies are not supplied as nominal CSV trajectories and cannot be selected.
